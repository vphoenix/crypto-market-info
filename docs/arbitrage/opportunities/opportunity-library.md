## ARB-0001：多链同名资产 CEX 同质化跨链套利

【机会来源】
多链同名资产在链上存在价格分化，但 CEX 将不同链入账资产记为同一账户余额，形成隐含跨链转换层。

【执行路径】
在低价链上买入同名资产 -> 充值至支持该链的 CEX -> 在 CEX 账户内获得统一余额 -> 提现到高价链或直接卖出/转移实现价差。

【适用资产类别】
多链发行的同名代币、跨链封装资产、稳定币、交易所支持多网络充提的资产。

【当前证据等级】
E1：规则可行，待具体资产与交易所数据验证。

【关键数据】
各链 DEX 价格、CEX 充提网络支持、到账确认时间、提现链选择、CEX 现货价格、手续费、滑点、充提暂停状态、最小充提额度。

【主要风险】
CEX 暂停充提、不同链资产并非真实同质、入账延迟、提现受限、流动性不足、价差回归、合规/KYC 风险。

【合并记录】
无。

## ARB-0002：跨平台永续资金费率错位套利

【机会来源】
同一标的在不同永续平台上的资金费率出现结构性错位，通过多空对冲赚取净资金费。

【执行路径】
在高资金费平台做空收取资金费 -> 在低资金费或负资金费平台做多对冲 Delta -> 持有到资金费结算 -> 动态再平衡保证净敞口接近中性。

【适用资产类别】
主流币永续、山寨币永续、CEX/DEX perp、同标的不同保证金币本位/USDT 本位合约。

【当前证据等级】
E1：规则可行，待抓取具体平台资金费率与盘口数据后升级到 E2。

【关键数据】
资金费率、结算频率、盘口深度、开平仓手续费、借贷/保证金成本、基差、指数价格规则、强平价格、资金费上限与历史持续性。

【主要风险】
资金费快速反转、两边价格指数不同、强平风险、滑点、交易所风控、API/撮合延迟、保证金资产波动。

【合并记录】
无。

## ARB-0003：收益型封装资产/赎回权折价赎回套利

【机会来源】
收益型封装资产、质押份额或可转让赎回权在二级市场折价交易，折价大于官方赎回等待期成本与摩擦成本时，买入并赎回。

【执行路径】
监控封装资产或赎回凭证二级市场价格 -> 计算相对官方 NAV/赎回金额的折价 -> 买入折价份额或凭证 -> 按协议规则排队赎回/到期结算 -> 回收底层资产。

【适用资产类别】
LST、LRT、vault token、质押份额、排队赎回 NFT/凭证、可转让 withdrawal claim。

【当前证据等级】
E1：协议机制可行，待指定协议与二级市场数据验证。

【关键数据】
二级市场价格、官方 NAV、赎回比例、等待期、退出队列长度、底层资产价格、对冲成本、赎回手续费、流动性深度、协议合约规则。

【主要风险】
赎回延期、协议坏账或削减、底层资产价格波动、二级市场流动性不足、凭证权利解释错误、智能合约风险、退出规则变更。

【合并记录】
Shadow 的“可转让赎回凭证折价套利”并入本条，作为赎回权凭证子类，不单独编号。

## ARB-0004：可执行报价/清算机制与外部 hedge 市场错位套利

【机会来源】
协议、OTC、AMM、清算器或拍卖机制给出的可执行价格，与外部可对冲市场价格短时偏离。

【执行路径】
锁定协议内报价或清算价，同时在 CEX/DEX/衍生品市场反向 hedge，完成成交后平仓。

【适用资产类别】
现货、LP 头寸、抵押品、清算资产、长尾资产。

【当前证据等级】
E1：机制可行，待具体报价源、成交成功率和 hedge 市场数据验证。

【关键数据】
可执行报价、外部 hedge 深度、滑点、成交延迟、手续费、gas、失败率。

【主要风险】
报价撤销、MEV、链上拥堵、hedge 不足、oracle 更新、流动性枯竭。

【合并记录】
A-R002/A-R003/A-R004/A-R005/A-R008/A-R009/C-R007 并入本类。

## ARB-0005：交易规则离散化套利

【机会来源】
最小报价单位、最小下单量、价格档位、舍入、批量撮合等离散规则造成可锁定价差。

【执行路径】
利用 tick/lot/rounding 差异构造双边或跨场所组合订单，锁定规则边界收益。

【适用资产类别】
现货、永续、交割合约、期权、预测市场。

【当前证据等级】
E1：规则可行，待交易规则与逐笔成交回放验证。

【关键数据】
tick size、lot size、rounding 规则、撮合优先级、订单簿深度、费率。

【主要风险】
规则变更、成交不完整、排队失败、手续费吞噬收益。

【合并记录】
S-R009 中与交易规则离散化相关部分并入。

## ARB-0006：Maker 返佣/负净手续费套利

【机会来源】
maker rebate、交易挖矿或负净手续费超过真实对冲成本。

【执行路径】
在真实市场风险可控前提下提供 maker 流动性，并用外部市场或同市场 taker/衍生品对冲。

【适用资产类别】
CEX 现货、永续、期权、DEX 激励池。

【当前证据等级】
E1：费率规则可行，待真实成交概率与逐笔净 PnL 验证。

【关键数据】
maker/taker 费率、返佣规则、成交概率、spread、hedge 成本、撤单限制。

【主要风险】
自成交/刷量合规风险、返佣取消、库存风险、成交选择性逆向。

【合并记录】
S-R009 中返佣/费率部分并入；明确排除自成交与刷量。

## ARB-0007：交割合约/现货基差收敛套利

【执行路径】

【适用资产类别】
BTC、ETH、主流币、流动性交割合约。

【当前证据等级】
E1：市场结构可行，待历史基差、借贷成本和交割规则验证。

【关键数据】
基差、到期时间、年化收益、借币成本、保证金要求、交割规则。

【主要风险】
保证金追加、现货借贷成本、交割规则变化、流动性不足。

【合并记录】
B-R005 中基差/融资相关部分并入。

## ARB-0009：期权平价/隐含融资曲线偏离套利

【当前证据等级】

【关键数据】
期权 IV、期限结构、执行价、现货价、利率、资金费、保证金占用。

【主要风险】
保证金模型、提前行权规则、波动率跳变、盘口深度不足。

【合并记录】
B-R003 作为波动率期限结构子类；S-R006 中衍生品隐含收益率部分并入。

## ARB-0010：结算/计息/快照时间错位套利

【机会来源】
不同市场或协议的结算、计息、快照、rebase、资金费时间点不一致。

【执行路径】
在关键时间窗口前后切换持仓，获取收益、避免成本或对冲净敞口。

【适用资产类别】
质押资产、借贷资产、永续、rebase 资产、收益凭证。

【当前证据等级】
E1：规则可行，待时间窗口和执行延迟数据验证。

【关键数据】
快照时间、计息频率、结算窗口、资金费时间、跨链到账时间、赎回延迟。

【主要风险】
时间戳偏差、到账失败、规则变更、拥堵导致错过窗口。

【合并记录】
S-R003 并入；不得重复 ARB-0001 的跨链同名资产同质化套利。

【执行路径】

【适用资产类别】

【关键数据】
oracle 价格、LTV、清算阈值、折扣率、借贷利率、可借深度、对冲成本。

【主要风险】

【合并记录】
B-R006 并入为资本效率子类。

## ARB-0012：清算/强平/坏账折价套利

【机会来源】

【执行路径】
参与清算、拍卖或坏账处置，买入折价资产并即时卖出或 hedge。

【适用资产类别】

【当前证据等级】

【关键数据】
清算折扣、债务规模、拍卖规则、外部深度、gas/MEV、清算竞争强度。

【主要风险】
竞争失败、MEV 抢跑、资产无法退出、坏账扩大、协议暂停。

【合并记录】
B-R008/C-R003/C-R004/S-R002 并入；S-R002 不单独新增。

## ARB-0013：借贷利率曲线/Kink 错配套利

【机会来源】
借贷协议利率模型、利用率 kink、激励或跨市场资金价格不同步。

【执行路径】
在低成本市场借入，在高收益或高借贷需求市场供应/放贷，并控制流动性与期限风险。

【适用资产类别】
稳定币、ETH、BTC、主流抵押资产。

【当前证据等级】
E1：规则可行，待供借利率、容量和流动性验证。

【关键数据】
供借利率、利用率、kink 参数、激励 APR、提款流动性、资金容量。

【主要风险】
利率快速回落、提款拥堵、激励结束、递归杠杆清算。

【合并记录】
B-R005 中借贷利率错配部分并入。

## ARB-0014：Delta-neutral LP 费用/LVR 净收益套利

【机会来源】
AMM LP 手续费与激励收益超过 LVR、无常损失和 hedge 成本。

【执行路径】
提供 LP，同时用永续、现货或期权动态对冲 delta，提取费用净收益。

【适用资产类别】
主流 AMM 池、稳定池、LST/ETH 池、高费率长尾池。

【当前证据等级】
E1：机制可行，待历史成交量、波动率、LVR 和 hedge 成本验证。

【关键数据】
手续费 APR、成交量、波动率、LVR、hedge 成本、再平衡频率、池深度。

【主要风险】
波动率上升、hedge 滞后、池子参数变化、激励衰减。

【合并记录】
无顶层合并项。

## ARB-0015：公开 Keeper/Vault/参数变更后的可对冲再定价套利

【机会来源】
公开规则、keeper flow、vault 调仓或治理参数变更导致价格应重新定价，但市场反应滞后。

【执行路径】
监控公开变更与链上队列，提前或同步建立可 hedge 仓位，等待市场重估。

【适用资产类别】
vault 份额、自动化策略代币、借贷市场、AMM 池、衍生品协议。

【当前证据等级】
E1：规则可行，待事件历史和可对冲性验证。

【关键数据】
治理提案、执行时间锁、keeper 队列、vault 仓位、参数变更影响、市场深度。

【主要风险】
变更取消、执行失败、信息已被定价、无法充分 hedge。

【合并记录】
C-R010 并入为公开规则变更/keeper-flow 再定价子类。

## ARB-0016：单资产收益/可对冲本金净收益套利

【机会来源】
质押、借贷、资源租赁、协议手续费、单币激励、稳定币存款或 CEX Earn 等产品产生收益；在协议正常经济规则下，本金没有不确定损失，或只承受可预先扣除的固定损失。

【执行路径】
采集收益率、额度、费用、锁仓和赎回规则 -> 排除规则内存在不确定本金损失的产品 -> 对非稳定币本金另行验证价格对冲深度 -> 按持有期扣除固定成本。永续资金费率不计入长期收益率。

【适用资产类别】
无不确定罚没的原生质押、可确定赎回的流动性质押、单资产借贷、无本金损失分担的手续费收益、资源租赁、单资产激励、稳定币储蓄和简单 CEX Earn。AMM LP、存在不确定罚没的再质押、期权卖方、双币理财和杠杆循环仓位不属于本机会。

【当前证据等级】
E1：规则可行，待激励可兑现性、稀释和退出成本验证。

【关键数据】
公布 APR/APY、计息档位、奖励资产、收益来源、固定费用、固定罚金、锁仓期、解质押期、规则内本金损失方式、额度、TVL、链上区块位置及本金价格暴露。

【主要风险】
规则识别错误、收益率变化、奖励币贬值、产品规则调整、退出受限，以及后续需要人工判断的交易所、合约、稳定币、桥和二层网络风险。

【合并记录】
S-R008 并入；与单纯刷量、不可兑现积分及规则内存在不确定本金损失的收益产品区分。数据采集设计见 [`../strategies/arb-0016-yield-data.md`](../strategies/arb-0016-yield-data.md)。

## ARB-0017：可替代交割/履约资产同权不同价套利

【机会来源】
协议、交易所或合约中被同等接受的多种交割、抵押、履约资产，在二级市场价格不同。

【执行路径】
识别被同等接受的多种交割/抵押/履约资产 -> 买入折价资产 -> 用其履约、交割、偿债或抵押 -> 同时卖出或对冲高价同权资产敞口，锁定价差。

【适用资产类别】
稳定币、封装资产、跨链映射资产、LST/LRT、抵押品、交割合约资产、可赎回凭证。

【当前证据等级】
E1：规则可行，待合格资产清单、折算规则和现货深度验证。

【关键数据】
合格资产清单、计价/折算规则、haircut、现货价差、深度、交割窗口、赎回/提现限制、资金费率、手续费。

【主要风险】
规则临时变更、资产资格失效、赎回延迟、流动性不足、同权假设不成立、对冲腿滑点。

【合并记录】
新增顶层机会，来源 A-R011。

## ARB-0018：库存权/提币权/可提取性溢价套利

【机会来源】
账面余额、不可提资产、可立即提取资产和可交割库存代表不同权利，市场会为可提取性支付溢价或折价。

【执行路径】
比较“账面余额/不可提资产”和“可即时提取资产”的价格差 -> 低价买入受限库存权 -> 卖出可提取现货或使用可提取资产对冲 -> 待提现恢复、库存释放或内部转让完成后平仓。

【适用资产类别】
中心化交易所余额、链上托管凭证、桥接资产、锁仓资产、排队赎回份额、场外库存权。

【当前证据等级】
E1：权利结构可行，待库存转让、提币状态和对冲市场验证。

【关键数据】
提现状态、排队长度、预计释放时间、场内外价差、可提资产溢价、库存深度、转让限制、平台信用风险。

【主要风险】
提现永久受限、平台违约、排队时间超预期、折价资产无法转让、对冲成本上升、监管或风控冻结。

【特别风险警示】
本类机会属于高危类型。折价可能不是可收敛价差，而是市场对平台违约、桥失效、储备不足、监管冻结或库存权无法兑现的风险定价；在最坏情况下，受限库存权可能永久无法恢复为可提取资产，导致本金大幅损失甚至全部损失。若缺少链上可验证储备、明确恢复机制和可执行退出路径，不应按低风险套利处理。

【合并记录】
新增顶层机会，来源 A-R012。

## ARB-0019：合法批量撮合/环路净额清算套利

【机会来源】
多账户、多资产、多场所之间存在可净额清算的环路需求，批量撮合或内部化结算可以减少外部成交成本并产生 surplus。

【执行路径】
扫描公开订单簿、intent 池、OTC/RFQ 需求或多边结算需求 -> 找到可净额清算的环路 -> 按规则提交批量撮合、solver 方案或内部化结算 -> 将节省的价差、手续费或滑点转化为收益。

【适用资产类别】
现货、稳定币、跨链资产、OTC 订单、RFQ、DEX 聚合路径、机构多边清算需求。

【当前证据等级】
E1：机制可行，待撮合规则、订单有效期和可实现 surplus 验证。

【关键数据】
参与方买卖方向、报价差、手续费、gas 成本、滑点、最小成交量、结算周期、KYC/合规要求、对手方信用。

【主要风险】
撮合失败、对手方违约、合规边界不清、信息泄露、结算不同步、批量路径中单腿失败。

【合并记录】
新增顶层机会，来源 A-R015；排除抢跑、操纵和违反平台规则的 MEV。

## ARB-0020：存量仓位祖父权/规则版本权套利

【机会来源】
协议、积分、空投、质押、赎回、白名单、费率或额度规则升级前后，旧仓位继续适用旧规则，新仓位适用新规则，形成可交易的规则版本权。

【执行路径】
识别“旧仓位继续适用旧规则、新仓位适用新规则”的版本差异 -> 买入、承接或保留具备祖父权的存量仓位 -> 用新规则下的可替代头寸或市场报价对冲 -> 捕获规则版本权溢价。

【适用资产类别】
LST/LRT、积分仓位、空投资格仓位、锁仓凭证、质押份额、赎回凭证、白名单额度、协议旧版本仓位。

【当前证据等级】
E1：规则可行，待祖父权可转让性、规则差额和对冲市场验证。

【关键数据】
规则变更公告时间、快照区块、旧仓位适用范围、新旧费率/额度/收益/赎回差异、祖父权是否可转让、二级市场折溢价、对冲工具流动性。

【主要风险】
规则解释变更、祖父权不可转让、协议治理追溯调整、快照识别错误、流动性不足、对冲不完全。

【合并记录】
新增顶层机会，来源 A-R016；与既有赎回权、额度权、积分权机会相关，但核心差异是规则版本权/旧仓位待遇差异。

## ARB-0021：本金权/收益权/附属权益/结构化仓位拆分后的重组平价套利

【机会来源】
资产、仓位或权利被拆分为本金权 PT、收益权 YT、claim 权、迁移凭证、附属权益、结构化分层份额或其他可组合组件后，拆分组件合成价格与完整资产价格、赎回价值、迁移价值或到期价值偏离。

【执行路径】
比较“拆分组件合成价格”和“完整资产价格/赎回价值/迁移价值/到期价值” -> 组件便宜时买入并重组为完整资产或完整仓位，或完整资产便宜时买入后拆分出售组件 -> 锁定重组平价差。

【适用资产类别】
Pendle 类 PT/YT、LST/LRT 收益拆分资产、固定收益代币、可确定结算的 claim 权、迁移凭证、到期赎回凭证、结构化 DeFi 仓位、高级/劣后分层份额。

【当前证据等级】
E1：机制可行，待 split/merge/redeem 路径、组件价格和流动性验证。

【关键数据】
组件价格、完整资产或完整仓位价格、底层资产现价、到期赎回价值、迁移/合成公式、隐含收益率、拆分/重组手续费、到期时间、流动性深度、是否可无损合成与赎回。

【主要风险】
到期收益率假设错误、组件流动性不足、协议费用侵蚀价差、重组路径受限、附属权益不可转让、收益权或 claim 现金流不确定、底层资产脱锚。

【合并记录】
新增顶层机会，来源 C-R016；核心是拆分组件与完整资产之间的重组平价。Round 021-025 中的 A-R021、B-R021、B-R025、C-R023、C-R025 等候选并入本类，作为附属权益、迁移凭证、canonical claim、期限扩展权和结构化分层份额的子类。

## ARB-0022：跨 CEX 同币种现货盘口价差套利

【机会来源】
同一现货交易对在不同中心化交易所的可执行订单簿价格短时偏离，扣除双边手续费、滑点、库存再平衡成本和执行失败风险后仍存在正价差。

【执行路径】
监控多个 CEX 的同一 normalized symbol 盘口 -> 在低价交易所买入 base asset -> 在高价交易所卖出 base asset -> 使用预置库存或后续转账完成库存再平衡 -> 记录净价差与执行质量。

【适用资产类别】
BTC/USDT、ETH/USDT、SOL/USDT 等主流 CEX 现货交易对，以及具备足够订单簿深度、充提通道和库存管理能力的同币种现货市场。

【当前证据等级】
E2：已有 `~/crypto-arb-observer` OKX/Binance 现货观察系统实现只读行情采集、盘口深度计算、机会生命周期记录和复盘数据写入；仍待真实成交、库存再平衡和执行失败率验证。

【关键数据】
多交易所 order book 深度、买入均价、卖出均价、可执行 base 数量、双边 taker/maker 费率、最小成交额、盘口时间差、行情延迟、账户库存、充提状态、提现手续费、到账时间、库存再平衡成本。

【主要风险】
两边无法同时成交、盘口延迟、成交不完整、价差回归、交易所风控、提现暂停、库存不足、手续费或滑点吞噬利润、API 限频、行情连接异常。

【特别实现提示】
本类机会如果临时在两个交易所之间转账，通常会错过窗口；更现实的实现方式是预先在多个 CEX 保留 base/quote 库存，先用库存完成同步买卖，再在价差消失后做慢速库存再平衡。观察系统只能证明存在可观测价差，不能直接证明可实盘成交。

【合并记录】
新增顶层机会，来源为 Ubuntu 上 `~/crypto-arb-observer` 的 OKX/Binance 现货跨场所套利观察系统审计。它不同于 ARB-0001 的多链同名资产 CEX 同质化，也不同于 ARB-0004 的协议/清算/OTC 可执行报价错位；核心是跨中心化交易所的同一现货交易对订单簿价差。
