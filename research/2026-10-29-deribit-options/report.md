# 2026-10-29 Deribit 期权盘口逐项复查：是否真的没有机会

时间显示使用 UTC+8；计算和证据文件中的时间为 UTC。全部数据库访问为只读事务，并在每次查询前检查生产 writer 积压（旧积压必须为 0、近期待写不超过 300 批）；未下单、未读取账户、未修改采集程序或数据库。

## 结论

> 后续处理：2026-10-29 18:08（UTC+8）起主 collector 设置 `OPTIONS_KINDS=future`，停止采集期权盘口，只保留 Deribit 交割期货（42 个）与四个指数；历史期权数据保留在库中。

**确实没有机会。** 954 个分钟快照、约 1.47 亿次组合比较中，扣除标准费用后为正的次数是 **0**。数据覆盖 BTC/ETH 币本位与 USDC 线性的全部期权和同到期期货，每分钟约 2,556 个有效盘口。另有 7 个分钟按每秒回放，共 419 个有效秒、约 5,970 万次比较，扣费后同样为 0。

- **毛利为正的情况：**不计费用时，有 4,109 次观测、252 组不同组合的毛利为正，几乎全是平价、币本位与 USDC 交叉、线性蝶式这几类。其中最接近盈利的一次，毛利也只有入场费用的 0.86 倍，而且第一档只有 0.05 BTC，低于最小下单量。
- **费用敏感性：**这些机会的规模由费用决定。整段样本中每组不同组合按最佳一次各算一次：费用为标准的 75% 时合计 $0.41，50% 时 $18，25% 时 $181；完全免费才有 $2,303（约 16 小时）。这是零费率或返佣做市商靠挂单赚的钱，我们按普通等级吃单拿不到。
- **高波动时段没有更多机会：**3 个最大波动小时里，毛利为正的观测是每分钟 4.4 次，平常时段 4.3 次，最好的一次反而更差（0.77 倍 vs 0.86 倍）。
- **Box：**买 box（放贷）扣费后在所有期限都是负利率。卖 box（借款）超过 90 天的币本位最低约 0.4%–0.8%/年、中位 0.9%–1.3%；30–90 天 USDC 线性中位约 1.9%–2.1%。这说明 Deribit 期权几乎按零利率定价，卖 box 相当于低息借款。但这需要占用保证金，是融资方式而不是套利，能否把借到的钱移作他用取决于账户保证金规则，公开数据无法验证。

**建议：**关闭期权盘口采集（约 14.6 GB/日）。远月期货和指数是唯一能锁定的正收益（BTC 期现约 5%）的输入，应保留，这需要小改代码，让期权链路可以只采期货和指数。

## 1. 数据范围

- **分钟抽样：**16 个一小时窗口（10-16 至 10-29），其中 13 个每天轮换不同钟点，另 3 个是 BTC 期货一小时振幅最大的时段（10-20 15:00、10-26 13:00、10-29 01:00 UTC）。10-14、10-15 没有覆盖率达到 58 分钟的小时，不在样本里。
- **快照：**每个窗口每分钟取第 0 秒的完整 10 档期权盘口和 5 档期货盘口，共 954 分钟。导出的全部行第 0 秒都有效，没有冲突重复行，也没有交叉盘口。
- **覆盖率：**每分钟平均 2,556 个有效盘口，应有约 2,650–2,980 个合约。10-20 15:00 这个波动小时采集本身有缺口，平均只有 1,008 个，10-26 13:00 为 2,215 个，其余窗口 2,580–2,795 个。
- **逐秒回放：**7 个分钟（毛利为正观测最多的分钟和最接近盈利的分钟）按 `internal/replay` 的规则回放全链 60 秒：按价格差量、数量 0 表示删除，有效位逐秒判断。回放结果与该分钟第 0 秒快照逐合约完全一致。
- **对照：**09-21 只查了 24 个期权约 19 小时；10-16 只查了一秒钟、1,003 个有效期权，而且没有币本位平价、非相邻蝶式、日历和币本位/USDC 交叉。本轮覆盖全链、全部行权价组合，并且跨 16 天。

## 2. 检查了什么

每一项都用真实可成交方向：买入用卖一、卖出用买一；每条腿都按同一秒的已存盘口；金额用整数（原始 1e-8 单位，行权价按整数缩放）精确计算，没有二进制浮点数参与判定。

| 检查 | 腿数 | 判定（以 1 个标的币为单位） |
|---|---:|---|
| 单腿下界 | 2 | 买期权＋同到期期货对冲后终值不低于内在价值：线性 `F_bid−K−C_ask`、`K−F_ask−P_ask`；币本位 `1−K/F_bid−c_ask`、`K/F_ask−1−p_ask` |
| 币本位 call 上界 | 1 | `c_bid > 1` 币 |
| 平价转换／反转换 | 3 | 线性 `F_bid−K−C_ask+P_bid`、`K−F_ask+C_bid−P_ask`；币本位按 K 美元名义对冲：`1−K/F_bid−c_ask+p_bid`、`K/F_ask−1+c_bid−p_ask` |
| 垂直价差单调性 | 2 | 所有行权价对（不只相邻）：低 K call 卖一低于高 K call 买一；put 反向 |
| 垂直价差上界 | 2 | 所有行权价对：卖出价差收到的权利金超过最大赔付。线性上界 `K2−K1`；币本位 call 价差上界 `(K2−K1)/K2` 币；币本位 put 价差的币赔付在指数下跌时无上限，只能把收到的币按同到期期货买一锁成美元后与 `K2−K1` 比较 |
| 蝶式凸性 | 3 | 两翼相距不超过 8 个挂牌行权价的全部三元组，非等距按行权价比例配权；负成本即套利 |
| 日历 | 2 | 币本位 call 同行权价：近月买一高于远月卖一，且远月期货不低于近月期货（需要在近月到期时平掉远月，不是锁定收益） |
| Box | 4（＋期货） | 全部行权价对，每 5 分钟一次：买 box（放贷）和卖 box（借款）扣费后的可成交年化利率；只计四腿第一档数量都达到最小下单量的 box |
| 币本位 vs USDC 线性 | 2＋期货 | 同标的、同到期、同行权价、同类型：USD 终值相同，币本位权利金按同到期期货价折成美元后比较 |

参考费用沿用 2026-09-20/09-21 研究记录的 Deribit 公开标准等级：期权每腿 `min(标的 × 3 bp, 权利金 × 12.5%)`，期货 5 bp。2026-10-29 官方费用页面拒绝自动访问，本轮未能重新核对。期权交割费、保证金占用、资金成本、超过第一档的滑点都没有扣除，它们只会让结果更差。

- **为什么毛利为正却赚不到：**这些正毛利能挂几十分钟，正因为它们小于费用，没人去吃。按普通等级，期权每腿 3 bp 的标的价值就是 BTC 约 $24/腿；它们的大小正好落在做市商的报价价差和费用之内。
- **币本位与 USDC 交叉：**两边 USD 终值相同，只差 USD 与 USDC 两个指数的基差。最大偏差约 $16/BTC，约 0.02%，远小于两腿费用。
- **静态边界：**垂直价差、日历和币本位上下界从未出现正毛利，最好也只是两边报价恰好相等。

**逐秒回放：**共 7 个分钟：10-16 08:26、10-17 00:17、10-23 23:13、10-26 13:11、10-29 01:43、10-29 01:47 为全链，10-20 15:30 那一分钟采集缺口只剩 100 个合约。合计 419 个有效秒、99.4 万个合约秒、约 5,970 万次比较。毛利为正的有 3,516 次（平价、交叉、线性蝶式），扣费后为正 0 次。最接近的一次仍是 10-23 23:13:10 的 `BTC-26OCT26-84000-C` 对 `BTC_USDC-26OCT26-84000-C`：毛利是费用的 0.86 倍，第一档 0.05 BTC，低于最小下单量。差量位图与差量行全部一致，回放出的第 0 秒与分钟快照逐合约相同。逐秒数据没有发现分钟抽样漏掉的机会。

## 4. Box 隐含的借贷利率

每 5 分钟取一次，在四腿第一档都达到最小下单量的 box 中，取扣入场费用后最好的可成交年化利率（单利），按期限分组：

| 族 | 期限 | 买 box（放贷）最好 / 中位 | 卖 box（借款）最好 / 中位 | 借款侧第一档中位容量 |
|---|---|---|---|---|
| BTC 币本位 | >90 天 | −0.54% / −0.88% | 0.39% / 0.94% | 2 BTC |
| BTC 币本位 | 30–90 天 | −1.39% / −3.07% | 1.43% / 3.43% | 4 BTC |
| BTC USDC | 30–90 天 | −0.71% / −2.19% | 0.62% / 2.05% | 10 BTC |
| ETH 币本位 | >90 天 | −0.69% / −1.30% | 0.80% / 1.29% | 18 ETH |
| ETH 币本位 | 30–90 天 | −1.15% / −3.56% | 2.25% / 4.04% | 18 ETH |
| ETH USDC | 30–90 天 | −0.48% / −1.88% | 0.36% / 1.85% | 150 ETH |
| 各族 | 7–30 天 | −1.9% 至 −8.3% | 2.7% 至 9.4% | — |
| 各族 | <7 天 | 负数百个百分点 | 正数百个百分点 | — |

- **期权按近似零利率定价：**放贷和借款两侧大致对称地落在 0% 两边，说明 Deribit 期权几乎按零利率定价（box 中间价接近行权价差本身）。短期限的利率被四腿价差和费用除以极短的期限放大，没有意义。
- **放贷没有机会：**买 box 扣费后在所有期限都是负利率，不能用来放贷。
- **借款侧是低息融资，不是套利：**卖 box 等于以约 1%–2%/年借入 USDC 或币。例如 10-16 USDC 线性 12 月到期的一个例子，主要靠以接近不贴现的内在价值卖出深度实值 put。如果借来的资金能用于约 5% 的远月期现套利，理论上有利差，但卖出的深度实值期权本身要占用保证金。标准保证金下这笔钱基本被锁住，只有组合保证金下 box 的风险才接近零。这需要账户层面的保证金规则和实测，公开盘口证明不了，本报告不把它算作机会。

## 5. 限制

- 只有 Deribit。OKX、Bybit、Binance 期权没有采集，跨所期权比较不在本轮范围。
- 没有采集 Deribit 原生 combo 盘口；手工拼出的多腿组合不能享受 combo 费用减免，也不能保证同时成交。
- 分钟抽样只看第 0 秒；另有少量分钟按每秒回放（见第 3 节），不能排除秒内更短暂的报价。
- 容量只取第一档；正毛利样本都很小，没有再向更深档位推算。
- 波动率风险溢价（卖期权收权利金）、偏度、期限结构交易属于承担风险的策略，不是静态套利，本轮没有评估。
