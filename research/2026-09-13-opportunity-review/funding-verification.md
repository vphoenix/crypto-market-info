# 永续资金费率候选独立验证

观察日：北京时间 2026-09-13；公开 API 快照主要取于 UTC 2026-09-12 19:13–19:23（北京时间 03:13–03:23）。研究只读取公开数据，没有账户、交易或采集配置操作。

**结论：ONG（Binance 多、Bybit 空）和 IOST（Bybit 多、OKX 空）存在值得继续观察的高资金费差，但目前不能证明任何一个是“净收益高且风险小”的可执行交易。完整 24 小时真实入出盘口缺失；当前预测延续 24 小时才能显出盈利，4–8 小时收租仍很难覆盖大额订单的完整成本。** 用户补充的 3.5% 门槛按全部占用资本净年化理解，本报告不把小时/单日高收益直接年化作为满足门槛的证据。

## 口径与数据完整性

- 本地 `soak-funding.json` 共 29,386 条小时记录，`is_actual=true` 13,948 条，按 `(instrument_id, funding_time)` 去重后仍为 13,948 条。大量应有结算缺失，**缺失不能填 0**。初筛所得的某些“大差价”只是缺失污染。
- 补读 Binance `/fapi/v1/fundingRate`、Bybit `/v5/market/funding/history`、OKX `/api/v5/public/funding-rate-history`；文件 `public-funding-{venue}-{symbol}.json` 保存 URL、采集 UTC 时间、原始响应解析结果和 SHA-256。OKX 第一次无 User-Agent 请求 403，添加普通项目客户端 User-Agent 后公开接口正常返回；无账户权限。
- Binance 的实际结算时间可偏离整点 1–8 毫秒，不能要求它和 Bybit 精确 timestamp 相同，也不能在 `16:00:00.000` 截断造成边界漏计。本报告完整共同窗口使用 **UTC 9/11 16:01 → 9/12 16:01**。
- 价格、费率、数量、现金流计算全部使用 Python `Decimal`；交易数量取两所 canonical 基础数量步长的公倍数。不同交易所的张数不直接相减：例如 IOST OKX 每张 1,000 IOST，Bybit 每单位 1 IOST。
- 盘口使用固定已提交 run `ca5f62f7-92c7-421a-a26b-adc6e0e82408` 的映射 revision `1f287a7cfe9fce6090da2a625f2e770afdf88eb8702c8bce2ecca4c7208f888a`，分钟秒 0 的 `valid_bitmap` 必须有效。
- 本次可用候选盘口仅始于 UTC 9/12 18:33，不能构造 UTC 9/11 16:01 的入场可成交价。因此以下**实际费率和不含完整基差的收益筛选，不等于已实现组合净利润**。
- 主 Agent 发现 BB、QNT 等股票/加密币同名映射污染。不能仅因 canonical symbol 一致就宣布同资产。ONG 官方 Binance 上币公告及 Bybit 资产页均为 Ontology Gas；IOST OKX 官方合约公告明确 IOST/USDT 指数，结合两边公开指数价格核对。ONE 另有分裂指数和负 carry 风险，排除低风险候选。

## 可复核的历史盘口短持模拟样本

ONG，UTC 9/12 18:59:00 开，19:01:00 平，12,350 ONG 每边；总开仓名义合计 1,999.67252 U。

- 按四笔历史可见盘口模拟的 VWAP：Binance 买 0.080775411336...；Bybit 卖 0.081141391902...；Binance 平仓卖 0.080765217813...；Bybit 平仓买 0.081233689879...。没有真实订单成交，手续费仍为前述费率情景。
- 价格及基差总损益：-1.26577 U；四腿费用 2.100446128 U。
- 19:00 Binance 实际资金费率 -0.00050881，资金费历史直接给出结算标记价 0.08075；多头收入精确为 `12350 × 0.08075 × 0.00050881 = 0.507417132625 U`。Bybit 在 19:00 无结算，其下一次为 20:00，故此窗口 Bybit 资金费为 0。
- **模拟假设按历史可见盘口即时吃单且使用本文 taker 费率的情景净损益 -2.858798995375 U，约 -0.14296%/总资本。** 这不是实盘账户盈亏；该样本中的结算前后临时吃单不产生正利润。

19:14 的入场价差不是永久损失：组合价格利润始终为 `Q × [(short_entry - long_entry) + (long_exit - short_exit)]`。IOST 买贵卖便宜不代表该价差必然全部亏掉，退出时仍可能回收；真正承担的是价差的变化及进出价差/滑点。ONG 开仓收到了有利价差，也不等于立即实现无风险利润。
